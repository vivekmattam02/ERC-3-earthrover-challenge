# Architecture Decision Records (ADR)

This folder tracks architecture decisions that materially shape runtime behavior.

Format:
- `Status`: Proposed | Accepted | Superseded
- `Date`: YYYY-MM-DD
- `Context`: what forced this decision
- `Decision`: what we chose
- `Consequences`: what it enabled and what it cost
